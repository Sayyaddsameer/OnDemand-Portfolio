About Me

I'm a final-year Computer Science student (Class of 2027) at Aditya College of Engineering & Technology, an AWS Certified Developer – Associate and RHCSA-certified engineer who builds cloud-native backend systems. What genuinely pulls me in is serverless, event-driven architecture on AWS — taking a vague problem statement and turning it into a system that scales cleanly, fails gracefully, and costs almost nothing while it sits idle.

Most of my building happens in Python and FastAPI, containerized with Docker and wired together with services like Lambda, Step Functions, API Gateway, DynamoDB and SES. I care about the parts that never show up in a demo — idempotency, eager-loaded queries, zero-trust IAM, cold-start times — because that's the gap between a project that looks finished and one that actually holds up under load. I sharpen the fundamentals behind all of it through 400+ solved DSA problems across LeetCode and GeeksforGeeks, and I'm looking for a role where I can keep shipping real cloud infrastructure.

Event-Driven Order Processing System

PROBLEM: Synchronous order pipelines fail under sudden traffic surges, lose messages, and cause double-processing during retries.

SOLUTION: An asynchronous, decoupled event-driven pipeline (API Gateway → Lambda → SQS → Lambda → SNS) guaranteeing at-least-once delivery.

KEY IMPLEMENTATION: Achieved zero duplicate orders via database-backed idempotency (ON CONFLICT DO NOTHING). Prevented message loss via SQS partial batch failure reporting (batchItemFailures) and Dead Letter Queue (DLQ) routing. Graceful degradation returning HTTP 202 on queue outages. Validated on LocalStack.

AWS Lambda SQS & SNS PostgreSQL AWS SAM LocalStack
